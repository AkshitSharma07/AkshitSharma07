<summary><h2>🛡️ Nmap Compliance Mapper (NIST CSF + ISO 27001)</h2></summary>

### Overview

Developed a Python-based compliance automation tool that parses **Nmap XML vulnerability scan results**, maps findings to **NIST Cybersecurity Framework (CSF)** and **ISO/IEC 27001 Annex A** controls, and generates a professional PDF audit report.

This project demonstrates how technical vulnerability findings can be translated into compliance evidence for security assessments and client audits.
